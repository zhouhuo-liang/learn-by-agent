## 二、优先队列是接口，堆是实现

优先队列（priority queue）规定元素按优先级取出，而不是按进入顺序取出。

它需要的操作是：

```cpp
push(value);  // 加入元素
top();        // 查看优先级最高的元素
pop();        // 删除优先级最高的元素
empty();      // 判断是否为空
```

这里“最高优先级”由规则决定：

- 数字越小优先级越高：最小优先队列
- 数字越大优先级越高：最大优先队列

优先队列是抽象接口，可以用不同数据结构实现：

| 实现 | 插入 | 删除最高优先级 |
|---|---:|---:|
| 无序数组 | `O(1)` | `O(n)` |
| 有序数组 | `O(n)` | `O(1)` |
| 二叉堆 | `O(log n)` | `O(log n)` |
| 平衡 BST | `O(log n)` | `O(log n)` |

本课使用最常见、最实用的**二叉堆**。

## 三、最小堆

最小堆满足：

```text
父节点 <= 左孩子
父节点 <= 右孩子
```

例如：

```text
        1
      /   \
     2     8
    / \   /
   5   3 9
```

检查：

- `1 <= 2`、`1 <= 8`
- `2 <= 5`、`2 <= 3`
- `8 <= 9`

因此它是合法的最小堆。

堆只保证父子关系，不保证整个数组有序。
例如：

```text
1 2 8 5 3 9
```

不是升序数组，但可以是一棵合法最小堆。

根节点始终是整个堆的最小值。

## 四、完全二叉树与数组下标

堆是一棵完全二叉树，所以可以直接用数组或 `vector` 存储，不需要左右指针。

数组：

```text
下标： 0  1  2  3  4  5
值：   1  2  8  5  3  9
```

对应树：

```text
        0(1)
       /     \
    1(2)     2(8)
    /  \      /
3(5) 4(3) 5(9)
```

父子关系：

```cpp
parent = (i - 1) / 2;
left   = 2 * i + 1;
right  = 2 * i + 2;
```

这里使用整数除法。例如 `i = 4`：

```text
parent = (4 - 1) / 2 = 1
```

所以下标 `4` 的父节点是下标 `1`。

## 五、堆的数据结构

```cpp
struct min_heap {
    vector<int> data;
};
```

`data[0]` 是堆顶，也就是最小值。

使用 `vector` 的优点：

- 内存连续
- 访问下标是 `O(1)`
- 自动扩容
- 天生适合存放完全二叉树

## 六、插入 `push`

完整代码：

```cpp
void push(int value) {
    data.push_back(value);
    int i = data.size() - 1;

    while (i > 0) {
        int parent = (i - 1) / 2;

        if (data[parent] <= data[i]) {
            break;
        }

        swap(data[parent], data[i]);
        i = parent;
    }
}
```

### 1. 先放到数组末尾

```cpp
data.push_back(value);
```

把新元素放到树的最下层最右边，保持完全二叉树结构。

### 2. 从新元素位置开始

```cpp
int i = data.size() - 1;
```

因为下标从 `0` 开始，最后一个元素下标是 `size - 1`。

### 3. 与父节点比较

```cpp
int parent = (i - 1) / 2;
```

如果父节点已经不大于新元素：

```cpp
if (data[parent] <= data[i]) {
    break;
}
```

说明最小堆规则已经满足。

### 4. 违反规则就交换

```cpp
swap(data[parent], data[i]);
i = parent;
```

交换后，新元素上升到父节点的位置，继续检查上一层。

这个过程叫：

```text
sift up / bubble up
```

### 5. 插入 `1` 的完整过程

已有数组：

```text
3 5 8
```

追加 `1`：

```text
3 5 8 1
0 1 2 3
      ↑
      i
```

父节点是下标 `1`，值为 `5`：

```text
3 5 8 1
  ↑   ↑
parent i
```

因为 `5 > 1`，交换：

```text
3 1 8 5
  ↑
  i
```

现在父节点是下标 `0`，值为 `3`：

```text
3 1 8 5
↑ ↑
parent i
```

因为 `3 > 1`，继续交换：

```text
1 3 8 5
```

现在 `i == 0`，循环结束。

### 6. 时间复杂度

每次最多向上走一层，树高约为 `log n`：

```text
O(log n)
```

## 七、查看最小值 `top`

```cpp
int top() const {
    return data[0];
}
```

最小值始终在根节点，所以直接返回 `data[0]`。

时间复杂度：

```text
O(1)
```

注意：在空堆上调用 `top()` 会访问非法下标。
调用前应先确认：

```cpp
if (!h.empty()) {
    cout << h.top();
}
```

## 八、删除最小值 `pop`

完整代码：

```cpp
void pop() {
    if (data.empty()) {
        return;
    }

    data[0] = data.back();
    data.pop_back();

    size_t i = 0;

    while (true) {
        size_t left = 2 * i + 1;
        size_t right = 2 * i + 2;

        if (left >= data.size()) {
            break;
        }

        size_t smaller = left;

        if (right < data.size() && data[right] < data[left]) {
            smaller = right;
        }

        if (data[i] <= data[smaller]) {
            break;
        }

        swap(data[i], data[smaller]);
        i = smaller;
    }
}
```

你的代码使用 `int smaller`，在当前教学规模下可以正常运行。
更严谨的统一写法可以使用 `size_t smaller`。

### 1. 为什么不能直接删除根

根节点是 `data[0]`。

如果直接删除它，后面的元素全部前移，既会破坏树的父子关系，也会产生 `O(n)` 移动。

### 2. 用最后一个元素补到根

```cpp
data[0] = data.back();
data.pop_back();
```

例如：

```text
1 2 8 5 3 9
```

最后元素是 `9`：

```text
9 2 8 5 3
```

对应树：

```text
        9
      /   \
     2     8
    / \
   5   3
```

这时结构仍是一棵完全二叉树，但不再满足最小堆规则。

必须特别记住：

> 最后一个元素不一定是最大值。把它放到根上，不是为了保持最大值，而是为了保持完全二叉树结构。

反例：

```text
1 5 2 6 7 3
```

最后一个元素是 `3`，最大值是 `7`，但数组仍然是合法最小堆。

### 3. 向下调整 `sift down`

从根节点开始：

```cpp
size_t i = 0;
```

计算左右孩子：

```cpp
size_t left = 2 * i + 1;
size_t right = 2 * i + 2;
```

如果没有左孩子：

```cpp
if (left >= data.size()) {
    break;
}
```

当前节点就是叶子，调整结束。

先假设左孩子更小：

```cpp
size_t smaller = left;
```

如果有右孩子，而且右孩子更小：

```cpp
if (right < data.size() && data[right] < data[left]) {
    smaller = right;
}
```

让 `smaller` 指向较小的孩子。

如果当前节点不大于这个较小孩子：

```cpp
if (data[i] <= data[smaller]) {
    break;
}
```

已经满足最小堆，停止。

否则交换，并继续向下：

```cpp
swap(data[i], data[smaller]);
i = smaller;
```

这个过程叫：

```text
sift down / sink down
```

### 4. 删除 `1` 的过程

初始：

```text
1 2 8 5 3 9
```

把最后元素 `9` 放到根：

```text
9 2 8 5 3
```

根的孩子是 `2` 和 `8`，较小的是 `2`：

```text
9 > 2 -> 交换
```

得到：

```text
2 9 8 5 3
```

节点 `9` 的孩子是 `5` 和 `3`，较小的是 `3`：

```text
9 > 3 -> 交换
```

得到：

```text
2 3 8 5 9
```

现在 `9` 是叶子，调整结束。

下一次 `top()` 返回 `2`。

### 5. 时间复杂度

每次最多向下一层，所以：

```text
O(log n)
```

## 十一、与 STL `priority_queue` 对照

需要头文件：

```cpp
#include <queue>
#include <functional>
```

### 默认最大堆

```cpp
priority_queue<int> max_pq;
```

`top()` 返回最大值。

输出：

```text
9 8 5 3 2 1
```

### 指定最小堆

```cpp
priority_queue<int, vector<int>, greater<int>> min_pq;
```

`top()` 返回最小值。

输出：

```text
1 2 3 5 8 9
```

### 为什么第二个模板参数是 `vector<int>`

`priority_queue` 是容器适配器，需要指定底层容器：

```text
元素类型：int
底层容器：vector<int>
比较规则：greater<int>
```

### 你的实现与标准库的关系

```text
你的 min_heap         = 自己维护 vector + 自己写 sift up / sift down
std::priority_queue   = 标准库维护容器 + 调用 heap 算法
```

两者语义相同，都是优先队列。

## 十二、优先队列的应用

堆和优先队列以后会用在：

- 堆排序
- 找第 K 大 / 第 K 小元素
- 合并多个有序链表
- Dijkstra 最短路径
- 任务调度、定时器
- 事件优先级处理

主计划中的 L35 Dijkstra 会再次使用优先队列。

## 十三、易错点与纠正

### 1. 最小堆不是排序数组

合法：

```text
1 2 8 5 3 9
```

它不是升序，但满足父子关系。

### 2. 最后一个元素不一定是最大值

堆只限制父子关系，不限制数组最后一个值。
把最后元素补到根，是为了保持完全二叉树结构。

### 3. `pop()` 不返回值

标准用法：

```cpp
int minimum = h.top();
h.pop();
```

### 4. `top()` 前要判空

```cpp
if (!h.empty()) {
    cout << h.top();
}
```
