# AI 时代：图形学 × Agent 的机会地图

> 记录日期：2026-09-20（凌晨夜谈）
> 一次非正式的讨论，想到哪写到哪。不用背，当作视野拓展。

---

## 一、先分清两条线：图形学 × AI，图形学 × Agent

很多人把这两件事混在一起，其实是两个不同的结合方式。

---

## 二、图形学 × AI（算法层面）

| 方向 | 是什么 | 需要图形学的原因 |
|---|---|---|
| **神经渲染 / NeRF** | 用神经网络表示 3D 场景，从照片重建 | 相机模型、光线投射、体渲染 |
| **3D Gaussian Splatting** | 用一堆高斯球表示场景，实时渲染 | 光栅化、投影、混合 |
| **3D 生成（AIGC）** | 文字/图片 → 3D 模型、纹理、材质 | 网格、UV、光照一致性 |
| **可微渲染** | 让渲染管线可求导，反推材质/几何 | 渲染方程、梯度 |
| **超分与降噪** | DLSS、光追降噪（NVIDIA） | 采样、噪声模型、时序 |
| **数字人 / 虚拟人** | 面部捕捉、表情驱动、动画 | 骨骼、蒙皮、渲染 |
| **神经物理仿真** | 用机器学习加速/替代物理模拟 | 碰撞、流体、粒子 |

**一句话**：AI 负责"学"，图形学负责"画"和"算得对"。

---

## 三、图形学 × Agent（这才是你问的重点）

分四个层次，从浅到深：

### ① Agent 是"使用者"：调用图形工具
- Agent 生成 Blender 脚本、调用 OpenGL、生成 Three.js 场景
- 图形引擎暴露成 **MCP 工具**，Agent 直接调用（"加一个球体"、"把相机移到左边"）
- 这一层最现实，现在就能做

### ② Agent 是"创作者"：生成并迭代 3D 内容
- 文本 → 3D 资产，然后**多轮迭代修改**（"调亮一点"、"加个阴影"、"换成金属材质"）
- 判断生成质量需要图形学素养（光照对不对、拓扑乱不乱）

### ③ Agent 是"NPC"：游戏里的智能体
- 游戏 NPC 从"写死的脚本" → LLM 驱动的**有记忆、有目标、会对话**的智能体
- 图形学负责渲染，Agent 负责行为
- 代表：NVIDIA ACE、Inworld AI

### ④ Agent 是"居民"：仿真与具身智能
- 机器人在 **Isaac Sim / MuJoCo** 里训练 —— 这些仿真器本质就是图形学 + 物理引擎
- 世界模型（World Model）：从视频学会"世界怎么演化"，生成可交互的 3D 世界
- 代表：Genie、NVIDIA Cosmos、World Labs

---

## 四、还有一个反向关系：Agent 帮你做图形学

- 用 Agent 写 shader、调渲染 bug、生成测试用例、做性能分析
- **你现在正在做的事**：每天和 Agent 协作学习、维护计划文件、让 Agent 写笔记
- 这本身就是"Agent-native 工作流"，未来会越来越普遍

---

## 五、你的位置：为什么这个组合值钱

> **纯 AI 的人不懂渲染管线，纯图形的人不懂 AI —— 你两边都沾，就是稀缺。**

你的路径（C++ + 数据结构 + 线代 + 渲染原理）是**底层功底**，这是护城河；
Agent / AI 是**应用层的杠杆**，能让你一个人的产出顶几个人。

正确姿势：
- ❌ 不要为了追 Agent 就把图形学丢了
- ✅ **图形学当护城河，Agent 当杠杆**
- ✅ 用 Agent 去做图形学项目

---

## 六、一个可以放进作品集的项目（长远目标）

**"用自然语言生成 3D 场景并渲染出图片"**

架构：
1. 你自己写的渲染器（C++，图形学）—— 这是核心
2. 暴露成 MCP 工具：添加物体 / 移动相机 / 设置光照 / 渲染出图
3. Agent 负责把自然语言（"给我一个有阳光的海边场景"）翻译成一串工具调用
4. 渲染器执行，输出图片

**这个项目同时展示了**：图形学、C++ 工程、系统设计、AI 应用。
比"只写一个渲染器"亮眼得多，而且**大二就能开始搭骨架**。

---

## 七、结论

1. 图形学的底层知识**不会过时**——工具在变，渲染原理、数学、性能直觉不变
2. Agent 不会取代图形学，而是**需要图形学作为"手和眼"**
3. 你的优势组合：**C++ + 图形学 + 线代 + 会用 Agent**
4. 机会方向（实习可瞄）：神经渲染、3D 生成、仿真引擎、游戏 AI、数字人
5. 别忘了：先把渲染器做出来，其他都是在这之上的放大器

> 目标公司/团队参考：NVIDIA、腾讯游戏 AI、米哈游、字节图形/生成方向，以及做世界模型/3D 生成的初创团队。
