## 二、二维矩阵

二维矩阵：

```text
[ m00  m01 ]
[ m10  m11 ]
```

代码：

```cpp
struct Mat2 {
    double m00;
    double m01;
    double m10;
    double m11;
};
```

命名：

```text
m00 = 第 0 行第 0 列
m01 = 第 0 行第 1 列
m10 = 第 1 行第 0 列
m11 = 第 1 行第 1 列
```

---

## 三、矩阵乘向量

公式：

```text
[ m00  m01 ] [ x ]   [ m00*x + m01*y ]
[ m10  m11 ] [ y ] = [ m10*x + m11*y ]
```

代码：

```cpp
Vec2 multiply(const Mat2& m, const Vec2& v) {
    Vec2 result;

    result.x = m.m00 * v.x + m.m01 * v.y;
    result.y = m.m10 * v.x + m.m11 * v.y;

    return result;
}
```

记忆：

```text
结果 x = 矩阵第一行和输入向量做点积
结果 y = 矩阵第二行和输入向量做点积
```

## 四、恒等矩阵

```text
[ 1  0 ]
[ 0  1 ]
```

代码：

```cpp
Mat2 identity() {
    return {
        1, 0,
        0, 1
    };
}
```

乘向量：

```text
[ 1  0 ] [ x ]   [ x ]
[ 0  1 ] [ y ] = [ y ]
```

因此：

```text
I * v = v
```

测试：

```text
v = (2, 3)
I * v = (2, 3)
```

恒等矩阵相当于“不进行任何变换”。

## 五、缩放矩阵

```text
[ sx   0 ]
[  0  sy ]
```

代码：

```cpp
Mat2 scale(double sx, double sy) {
    return {
        sx, 0,
        0, sy
    };
}
```

作用：

```text
x 坐标乘以 sx
y 坐标乘以 sy
```

例如：

```text
s = scale(2, 0.5)
v = (2, 3)
```

计算：

```text
x' = 2 * 2 = 4
y' = 0.5 * 3 = 1.5
```

得到：

```text
S * v = (4, 1.5)
```

## 六、矩阵列向量就是变换后的坐标轴

矩阵：

```text
[ a  b ]
[ c  d ]
```

对标准 x 轴：

```text
(1, 0)
```

计算：

```text
[ a  b ] [ 1 ]   [ a ]
[ c  d ] [ 0 ] = [ c ]
```

第一列：

```text
(a, c)
```

对标准 y 轴：

```text
(0, 1)
```

计算：

```text
[ a  b ] [ 0 ]   [ b ]
[ c  d ] [ 1 ] = [ d ]
```

第二列：

```text
(b, d)
```

所以：

> 矩阵第一列是变换后的 x 轴，第二列是变换后的 y 轴。

这是理解所有线性变换的核心。

## 七、旋转矩阵

逆时针旋转角度 `θ` 的矩阵：

```text
[ cosθ  -sinθ ]
[ sinθ   cosθ ]
```

代码：

```cpp
Mat2 rotation(double radians) {
    double c = cos(radians);
    double s = sin(radians);

    return {
        c, -s,
        s,  c
    };
}
```

对应：

```text
m00 = c
m01 = -s
m10 = s
m11 = c
```

## 八、90° 旋转验证

90°：

```text
cos90° = 0
sin90° = 1
```

旋转矩阵：

```text
[ 0  -1 ]
[ 1   0 ]
```

对：

```text
v = (2, 3)
```

计算：

```text
x' = 0 * 2 + (-1) * 3 = -3
y' = 1 * 2 + 0 * 3 = 2
```

所以：

```text
(2, 3) 逆时针旋转 90°
= (-3, 2)
```

输出：

```text
R * v = (-3, 2)
```

---

## 九、用坐标轴理解 90° 旋转

90° 时：

```text
原 x 轴 (1, 0) -> (0, 1)
原 y 轴 (0, 1) -> (-1, 0)
```

也就是说：

```text
x 轴转到上方
y 轴转到左方
```

原向量：

```text
v = (2, 3)
  = 2 * x轴 + 3 * y轴
```

旋转后：

```text
v' = 2 * 上方向 + 3 * 左方向
   = (-3, 2)
```

结果与代码一致。

## 十、角度与弧度

C++ 的 `sin` 和 `cos` 接收弧度：

```cpp
sin(radians)
cos(radians)
```

不是角度。

转换公式：

```text
radians = degrees * PI / 180
```

代码：

```cpp
const double PI = 3.14159265358979323846;

double degrees_to_radians(double degrees) {
    return degrees * PI / 180.0;
}
```

常用值：

```text
90°  = PI / 2
180° = PI
360° = 2 * PI
```

## 十一、旋转矩阵的性质

二维旋转矩阵：

- 不改变向量长度
- 不改变原点
- 保持向量之间的夹角
- 保持手性
- 正角度在标准数学坐标系中表示逆时针

因为旋转前后的长度相等：

```text
|R(v)| = |v|
```

图形学中常用于：

- 物体旋转
- 相机旋转
- 2D 精灵方向
- 法线方向变换

---

## 十二、线性变换的含义

线性变换满足：

```text
T(a + b) = T(a) + T(b)
T(k * a) = k * T(a)
```

矩阵乘向量自然满足这两条性质。

线性变换不包含平移：

```text
不能把 (0, 0) 变成 (5, 0)
```

因为矩阵乘零向量一定得到零向量：

```text
M * (0, 0) = (0, 0)
```

平移将在 L21 用齐次坐标处理。

## 十四、易错点

### 1. 矩阵列的含义

正确说法：

```text
第一列 = 变换后的 x 轴
第二列 = 变换后的 y 轴
```

只说“x、y”不够准确。

### 2. 角度与弧度

`sin` 和 `cos` 都接收弧度，不只是 `sin`。

### 3. 旋转方向

标准数学坐标系：

```text
y 轴向上，正角度逆时针
```

屏幕坐标系经常是：

```text
y 轴向下
```

视觉上的旋转方向可能与数学坐标相反。

### 4. 矩阵不能表示平移

二维线性矩阵可以缩放、旋转、剪切、反射，但不能直接平移。

## 十六、结课结论

本课最重要的几句话：

1. 矩阵乘向量使用“矩阵每一行与向量点积”。
2. 矩阵第一列是变换后的 x 轴，第二列是变换后的 y 轴。
3. `scale(sx, sy)` 分别缩放 x、y 坐标。
4. 旋转矩阵是 `[cosθ, -sinθ; sinθ, cosθ]`。
5. `(2,3)` 逆时针旋转 90° 得到 `(-3,2)`。
6. 线性变换不能平移；平移将在 L21 使用齐次坐标。
