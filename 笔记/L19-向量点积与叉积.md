## 二、二维向量

向量表示方向和长度：

```text
v = (x, y)
```

代码：

```cpp
struct Vec2 {
    double x;
    double y;
};
```

使用 `double` 而不是 `int`，因为图形学中的坐标经过缩放、旋转和投影后通常是小数。

示例：

```cpp
Vec2 a = {3, 4};
Vec2 b = {1, 2};
```

---

## 三、为什么参数使用 `const Vec2&`

函数：

```cpp
double dot(const Vec2& a, const Vec2& b)
```

拆开理解：

```text
const  -> 函数不能修改传入向量
Vec2&  -> 使用引用，不复制结构体
```

因此：

```cpp
const Vec2&
```

表示“高效地只读访问”。

## 四、点积

公式：

```text
a · b = a.x * b.x + a.y * b.y
```

代码：

```cpp
double dot(const Vec2& a, const Vec2& b) {
    return a.x * b.x + a.y * b.y;
}
```

示例：

```text
a = (3, 4)
b = (1, 2)
```

计算：

```text
a · b = 3 * 1 + 4 * 2
      = 3 + 8
      = 11
```

所以输出：

```text
dot(a, b) = 11
```

---

## 五、点积的几何意义

点积还可以写成：

```text
a · b = |a| |b| cos(θ)
```

其中 `θ` 是两个向量之间的夹角。

因此点积的正负可以判断夹角：

| 点积 | `cos(θ)` | 夹角 |
|---|---:|---:|
| 正数 | 正 | 小于 90° |
| 0 | 0 | 正好 90° |
| 负数 | 负 | 大于 90° |

### 垂直判断

```text
right = (1, 0)
up    = (0, 1)
```

计算：

```text
right · up = 1 * 0 + 0 * 1 = 0
```

所以：

```text
点积为 0 ⇔ 两个向量垂直 ⇔ 夹角为 90°
```

注意：不是夹角为 0°。夹角为 0° 时两个向量同方向，点积为正。

## 六、向量长度

二维向量长度：

```text
|a| = sqrt(a.x² + a.y²)
```

`dot(a, a)` 的计算：

```text
dot(a, a) = a.x * a.x + a.y * a.y
          = a.x² + a.y²
```

所以：

```cpp
double length(const Vec2& a) {
    return sqrt(dot(a, a));
}
```

因为：

```text
dot(a, a) = |a|²
sqrt(dot(a, a)) = |a|
```

对于：

```text
a = (3, 4)
```

计算：

```text
dot(a, a) = 3 * 3 + 4 * 4
          = 9 + 16
          = 25

length(a) = sqrt(25)
          = 5
```

输出：

```text
length(a) = 5
```

## 七、叉积

二维叉积的结果是一个标量：

```text
a × b = a.x * b.y - a.y * b.x
```

代码：

```cpp
double cross(const Vec2& a, const Vec2& b) {
    return a.x * b.y - a.y * b.x;
}
```

示例：

```text
a = (3, 4)
b = (1, 2)
```

计算：

```text
a × b = 3 * 2 - 4 * 1
      = 6 - 4
      = 2
```

交换顺序：

```text
b × a = 1 * 4 - 2 * 3
      = 4 - 6
      = -2
```

因此：

```text
cross(a, b) = -cross(b, a)
```

这叫反对称性。

## 八、叉积的正负与左右侧

叉积可以写成：

```text
a × b = |a| |b| sin(θ)
```

`sin(θ)` 的正负表示旋转方向：

| 叉积 | 方向 |
|---|---|
| 正数 | b 在 a 左侧，逆时针 |
| 负数 | b 在 a 右侧，顺时针 |
| 0 | a 和 b 共线 |

### 标准方向测试

```cpp
Vec2 right = {1, 0};
Vec2 up = {0, 1};
Vec2 left = {-1, 0};
```

#### `right` 和 `up`

```text
(1, 0) × (0, 1)
= 1 * 1 - 0 * 0
= 1
```

结果为正：

```text
up 在 right 的左侧
```

#### `right` 和 `left`

```text
(1, 0) × (-1, 0)
= 1 * 0 - 0 * (-1)
= 0
```

结果为 0：

```text
right 和 left 共线
```

它们方向相反，但位于同一条直线上。

## 九、叉积的几何意义

叉积的绝对值：

```text
|a × b| = |a| |b| |sin(θ)|
```

等于两个向量组成的平行四边形面积。

因此叉积同时包含：

```text
绝对值 -> 面积大小
正负号 -> 旋转方向
```

图形学中常用它判断：

- 点在线段左侧还是右侧
- 三角形是顺时针还是逆时针排列
- 两条线段是否相交
- 光栅化时像素是否位于三角形内部

## 十、完整测试结果

```text
a = (3, 4)
b = (1, 2)
dot(a, b) = 11
length(a) = 5
cross(a, b) = 2
cross(b, a) = -2

```

对应结论：

| 测试 | 结果 | 结论 |
|---|---:|---|
| `dot(a, b)` | 11 | 夹角小于 90° |
| `length(a)` | 5 | `(3,4)` 长度为 5 |
| `cross(a, b)` | 2 | `b` 在 `a` 左侧 |
| `cross(b, a)` | -2 | 交换顺序后符号相反 |
| `dot(right, up)` | 0 | 两个方向垂直 |
| `cross(right, up)` | 1 | `up` 在 `right` 左侧 |
| `cross(right, left)` | 0 | 两个方向共线 |

## 十二、易错点

### 1. 点积为 0 的含义

```text
dot(a, b) = 0 -> 夹角为 90°，垂直
```

不是夹角为 0°。

### 2. 同方向与反方向

| 关系 | 点积 | 叉积 |
|---|---:|---:|
| 同方向 0° | 正数 | 0 |
| 反方向 180° | 负数 | 0 |
| 垂直 90° | 0 | 非 0 |

### 3. 叉积是标量

二维叉积返回一个数：

```cpp
double cross(...)
```

不要误以为返回的是二维向量。

### 4. 叉积交换顺序符号变化

```text
cross(a, b) = -cross(b, a)
```

## 十三、后续应用

### 1. 判断点在直线哪一侧

```text
cross(line_end - line_start, point - line_start)
```

结果正负表示点在左侧或右侧。

### 2. 判断三角形绕序

```text
cross(B - A, C - A)
```

- 正数：逆时针
- 负数：顺时针
- 0：三点共线

### 3. 光照

点积用于计算方向与法线之间的夹角，从而计算光照强度。

### 4. 相机方向

点积可以判断物体是否位于相机前方。

## 十五、结课结论

本课最重要的几句话：

1. `dot(a, b) = a.x*b.x + a.y*b.y`，为零表示垂直。
2. `cross(a, b) = a.x*b.y - a.y*b.x`，正负表示左右方向。
3. `dot(a, a) = |a|²`，所以长度为 `sqrt(dot(a, a))`。
4. 叉积绝对值为平行四边形面积，符号表示旋转方向。
5. 同方向叉积为 0；垂直时点积为 0。
