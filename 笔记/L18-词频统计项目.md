## 三、按空白读取单词

```cpp
string word;

while (input >> word) {
    string cleaned = clean_word(word);

    if (!cleaned.empty()) {
        freq[cleaned]++;
    }
}
```

`input >> word` 会：

1. 跳过空格、换行、制表符
2. 读取下一个连续的单词
3. 到达文件末尾时返回 `false`

所以它可以自动跨行读取。

无标点处理前，文本会被拆成：

```text
Apple,
apple!
Banana.
banana?
Orange
and
apple.
Grapes,
grapes,
grapes!
```

直接统计会把 `Apple,`、`apple!`、`apple.` 当成不同 key，因此必须先清洗。

## 四、清洗单词 `clean_word`

```cpp
string clean_word(const string& word) {
    string result;

    for (char ch : word) {
        unsigned char c = static_cast<unsigned char>(ch);

        if (isalnum(c)) {
            result += static_cast<char>(tolower(c));
        }
    }

    return result;
}
```

### `isalnum`

```text
is alphanumeric = 是否为字母或数字
```

字母和数字保留，其他字符忽略。

| 原字符 | 是否保留 | 结果 |
|---|---:|---|
| `A` | 是 | `a` |
| `p` | 是 | `p` |
| `,` | 否 | 忽略 |
| `!` | 否 | 忽略 |
| `3` | 是 | `3` |

### `tolower`

把大写字母转成小写：

```cpp
'A' -> 'a'
'G' -> 'g'
```

### 为什么要转成 `unsigned char`

```cpp
unsigned char c = static_cast<unsigned char>(ch);
```

`isalnum` 和 `tolower` 的参数不能是负的字符值。
直接传入某些非 ASCII 字符可能产生未定义行为，因此先转换成 `unsigned char`。

### 清洗示例

```cpp
clean_word("Apple,")   // "apple"
clean_word("apple!")   // "apple"
clean_word("Banana.")  // "banana"
clean_word("...")      // ""
```

空字符串不统计：

```cpp
if (!cleaned.empty()) {
    freq[cleaned]++;
}
```

## 五、使用 `unordered_map` 统计词频

```cpp
unordered_map<string, int> freq;
```

键值对含义：

```text
string -> 单词
int    -> 出现次数
```

核心代码：

```cpp
freq[word]++;
```

### key 不存在时

`operator[]` 会：

1. 自动插入新 key
2. `int` 执行值初始化，值为 `0`
3. 返回对应 value 的引用
4. 执行 `++`

所以：

```text
第一次遇到 apple
```

结果：

```text
apple -> 1
```

### key 已存在时

直接返回已有 value 的引用，再执行 `++`。

```text
apple 已存在且值为 2
```

执行：

```cpp
freq["apple"]++;
```

结果：

```text
apple -> 3
```

### 为什么要用 `unordered_map`

平均情况下：

```text
查找/插入 O(1)
```

所以统计 `N` 个单词平均是：

```text
O(N)
```

最坏情况下冲突严重，也可能退化到 `O(N)` 一次操作，但正常哈希分布下平均很快。

## 六、为什么 `unordered_map` 不能直接排序

程序需要按词频输出，但 `unordered_map` 的迭代顺序不保证稳定。

不能直接写：

```cpp
sort(freq.begin(), freq.end(), compare);
```

原因是：

- `unordered_map` 不提供稳定顺序
- 它的迭代器不是随机访问迭代器
- `sort` 需要可随机访问并重新排列的元素范围

因此需要复制到 `vector`。

---

## 七、复制到 `vector`

```cpp
vector<pair<string, int>> items(freq.begin(), freq.end());
```

每个元素都是：

```cpp
pair<string, int>
```

对应：

```text
first  -> 单词
second -> 次数
```

示例：

```cpp
pair<string, int> item = {"apple", 3};

item.first   // "apple"
item.second  // 3
```

`vector` 的范围构造函数会把 `freq` 中的每个键值对复制到 `items`。

复制后的初始顺序仍然不保证，但接下来会排序。

---

## 八、自定义比较器

```cpp
bool compare(const pair<string, int>& a,
             const pair<string, int>& b) {
    if (a.second != b.second) {
        return a.second > b.second;
    }

    return a.first < b.first;
}
```

规则：

1. 次数不同：次数大的排前面
2. 次数相同：字母顺序小的排前面

例如：

```text
apple  -> 3
banana -> 2
```

`apple` 排在前面，因为：

```text
3 > 2
```

如果：

```text
and    -> 1
orange -> 1
```

次数相同，比较：

```text
"and" < "orange"
```

所以 `and` 排在前面。

---

## 九、排序

```cpp
sort(items.begin(), items.end(), compare);
```

`sort` 会不断调用比较器，判断两个元素谁应该排在前面。

排序前的 map 遍历顺序可能类似：

```text
orange 1
banana 2
apple 3
grapes 3
and 1
```

排序后：

```text
apple 3
grapes 3
banana 2
and 1
orange 1
```

## 十一、复杂度：分清 N 和 U

### N：总单词数量

`N` 是文本里所有单词数量，重复单词也计算。

你的输入共有：

```text
apple
apple
banana
banana
orange
and
apple
grapes
grapes
grapes
```

所以：

```text
N = 10
```

统计阶段处理全部单词：

```text
O(N)
```

### U：不同单词数量

去重后的不同单词：

```text
apple
banana
orange
and
grapes
```

所以：

```text
U = 5
```

排序阶段只处理不同单词：

```text
O(U log U)
```

### 总复杂度

```text
O(N + U log U)
```

两个阶段都要执行，所以复杂度相加。

如果所有单词都不同：

```text
U ≈ N
```

总复杂度：

```text
O(N + N log N)
= O(N log N)
```

如果大量单词重复、不同单词很少：

```text
U 很小
```

总复杂度主要由：

```text
O(N)
```

决定。

## 十二、常见易错点

### 1. 大小写不统一

```text
Apple
apple
```

会被当成两个 key。必须先 `tolower`。

### 2. 标点没有清理

```text
apple
apple,
apple!
```

会被当成三个 key。必须先去掉标点。

### 3. 空字符串也插入

纯标点清洗后可能是空字符串：

```text
"..." -> ""
```

必须跳过，否则会出现空 key。

### 4. 直接把 unordered_map 排序

不能直接 `sort`，必须先复制到 `vector<pair<string, int>>`。

### 5. 把 N 和 U 混为一谈

```text
N = 所有单词数量
U = 不同单词数量
```

统计处理 N 个，排序处理 U 个。

### 6. 文件名不一致

程序里写 `.text`，文件名却是 `.txt`，或者反过来，会导致文件打开失败。

## 十五、结课结论

本项目最重要的几句话：

1. `ifstream` 负责读取文件，`input >> word` 负责按空白拆词。
2. `clean_word` 统一大小写并去掉标点，保证同一个词能正确合并。
3. `freq[word]++` 利用 `unordered_map` 的 `operator[]` 完成统计。
