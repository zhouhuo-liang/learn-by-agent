## 二、你的第四题回答：基本正确 ✅

你写的是："递归的要素·是有结束条件，有自身调用"

这抓住了两个核心，精确表述是：

1. **递归基（结束条件 / 出口）**：最小的情况不再调用自己，直接返回
2. **递归步骤（自己调用自己）**：把大问题分解成**规模更小的同类问题**

再补一个**隐含的第三点**：每次调用必须让问题**变小**，保证最终一定能到达出口。
（如果问题不变小 → 永远到不了出口 → 无限递归 → 栈溢出 Stack Overflow）

## 三、第三题教学：用递归求树的高度

### 第 1 步：先把"高度"定义清楚

**本文约定**：高度 = 从根到最远的叶子所经过的**层数**

- 空树高度 = **0**
- 只有一个节点 = **1**

> 注意：另一种常见约定是数"边数"（空树 -1、单节点 0）。考试时看清题目要求。本文用"层数"。

### 第 2 步：递归思维的关键——"相信递归"

**不要在脑子里展开每一层**（会爆炸）。只问两个问题：

1. **出口是什么？** → 空树高度 = 0
2. **如果左右子树的高度都已经算好了，我这层怎么算？**
   → 我 = 1 + max(左高, 右高)

就是这两句话，代码就出来了。

### 第 3 步：代码

```cpp
int height(Node* p) {
    if (p == nullptr) return 0;          // 出口：空树高度为 0

    int lh = height(p->left);            // 相信它能算出左子树高度
    int rh = height(p->right);           // 相信它能算出右子树高度

    return 1 + (lh > rh ? lh : rh);      // 自己这层 +1，取较高的那棵子树
}
```

> 最后那行用了**三目运算符** `? :`，正是你在 L04 学过的写法：`条件 ? 真值 : 假值`。

### 第 4 步：用你的树逐步走一遍（关键！）

```
          1
        /   \
       2     3
      / \   / \
     4   5 6   7
                \
                 8
```

递归是**从叶子往上**算出结果的：

| 节点 | 左子树高度 | 右子树高度 | 自己的高度 = 1 + max |
|---|---|---|---|
| 4 | 0（空） | 0（空） | **1** |
| 5 | 0 | 0 | **1** |
| 6 | 0 | 0 | **1** |
| 8 | 0 | 0 | **1** |
| 7 | 0 | 1（来自 8） | **2** |
| 2 | 1（来自 4） | 1（来自 5） | **2** |
| 3 | 1（来自 6） | 2（来自 7） | **3** |
| 1 | 2（来自 2） | 3（来自 3） | **4** |

**所以整棵树的高度 = 4。**

> 观察计算顺序：先算子节点，再算父节点 —— 这正是**后序遍历**的顺序！
> 所以凡是"把子树结果汇总到父节点"的问题（高度、节点数、最大值…），后序的递归框架都特别自然。

### 第 5 步：常见错误

| 错误写法 | 问题 |
|---|---|
| 忘记写 `if (p == nullptr) return 0;` | 无限递归 → 栈溢出 |
| `return 1 + lh + rh;` | 这是**节点个数**，不是高度 |
| `return lh > rh ? lh : rh;` | 忘了 +1（自己这一层） |
| 把 max 写成 min | 求的是"最短路径"，不是高度 |

## 四、一个极重要的对比：count_node vs height

同一个递归骨架，**只差"合并方式"**：

```cpp
// 数节点个数：左右两边【相加】，再加自己
int count_node(Node* p) {
    if (p == nullptr) return 0;
    return 1 + count_node(p->left) + count_node(p->right);
}

// 求高度：左右两边【取较大】，再加自己
int height(Node* p) {
    if (p == nullptr) return 0;
    int lh = height(p->left);
    int rh = height(p->right);
    return 1 + (lh > rh ? lh : rh);
}
```

**记住这个模板：递归 = 出口 + 处理子问题结果。**
- 求和 / 计数 → 用 `+`
- 求最大 / 最小 / 高度 → 用 `max` / `min`

以后你遇到"用递归解决树的问题"，先想：**子问题的答案怎么合并成我的答案？**
