## 二、什么是二叉搜索树

普通二叉树只要求每个节点最多有两个孩子。  
二叉搜索树（Binary Search Tree，BST）额外要求：

```text
左子树所有节点的值 < 根节点的值 < 右子树所有节点的值
```

而且左右子树本身也必须是 BST。

本课建立的树：

```text
            8
          /   \
         3     10
        / \      \
       1   6      14
          / \    /
         4   7  13
```

以节点 `3` 为例：

- 左子树只有 `1`，`1 < 3`
- 右子树有 `6、4、7`，它们都 `> 3`
- 因为 `4、7` 在 `6` 的左右两侧，子树 `6` 也满足 BST 规则

### 中序遍历与排序

中序遍历顺序：

```text
左子树 → 根节点 → 右子树
```

BST 的中序遍历结果一定是升序：

```text
1 3 4 6 7 8 10 13 14
```

所以 `inorder` 不仅能遍历树，也可以当作 BST 结构是否正确的检查工具。

## 三、节点与创建函数

```cpp
struct Node {
    int value;
    Node* left;
    Node* right;
};
```

每个节点保存：

- 一个整数 `value`
- 左孩子地址 `left`
- 右孩子地址 `right`

没有孩子时，指针为 `nullptr`。

创建节点：

```cpp
Node* make_node(int v) {
    Node* n = new Node;
    n->value = v;
    n->left = nullptr;
    n->right = nullptr;
    return n;
}
```

`new Node` 创建的节点会持续存在，直到明确执行 `delete`。  
不能返回局部变量地址，因为函数结束后局部变量会销毁。

## 四、插入 `insert`

```cpp
Node* insert(Node* root, int v) {
    if (root == nullptr) {
        return make_node(v);
    }

    if (v < root->value) {
        root->left = insert(root->left, v);
    } else if (v > root->value) {
        root->right = insert(root->right, v);
    }

    return root;
}
```

### 1. 递归出口

```cpp
if (root == nullptr) {
    return make_node(v);
}
```

当前位置为空，说明这里就是新节点的位置。

### 2. 小往左，大往右

```cpp
if (v < root->value) {
    root->left = insert(root->left, v);
}
```

插入值更小，进入左子树。

```cpp
else if (v > root->value) {
    root->right = insert(root->right, v);
}
```

插入值更大，进入右子树。

### 3. 为什么必须接回指针

核心代码是：

```cpp
root->left = insert(root->left, v);
```

如果左指针原来是 `nullptr`，递归会返回一个新节点。  
只有把返回值赋给 `root->left`，父节点才会真正连接到新节点。

如果只写：

```cpp
insert(root->left, v);
```

新节点虽然创建了，但父节点不知道新节点在哪里，树会断开。

### 4. 为什么最后返回 `root`

插入完成后，上层需要拿到“插入后的子树根节点”，所以每一层都返回 `root`。

当在空位置创建节点时，返回的是新节点；其他层返回的都是原来的根节点。

### 5. 插入过程

插入顺序：

```text
8, 3, 10, 1, 6, 14, 4, 7, 13
```

| 插入值 | 路径 | 位置 |
|---:|---|---|
| 8 | 空树 | 根节点 |
| 3 | `3 < 8` | 8 的左孩子 |
| 10 | `10 > 8` | 8 的右孩子 |
| 1 | `1 < 8 → 1 < 3` | 3 的左孩子 |
| 6 | `6 < 8 → 6 > 3` | 3 的右孩子 |
| 14 | `14 > 8 → 14 > 10` | 10 的右孩子 |
| 4 | `4 < 8 → 4 > 3 → 4 < 6` | 6 的左孩子 |
| 7 | `7 < 8 → 7 > 3 → 7 > 6` | 6 的右孩子 |
| 13 | `13 > 8 → 13 > 10 → 13 < 14` | 14 的左孩子 |

最终结构：

```text
            8
          /   \
         3     10
        / \      \
       1   6      14
          / \    /
         4   7  13
```

## 五、查找 `search`

```cpp
bool search(Node* root, int target) {
    if (root == nullptr) {
        return false;
    }
    if (root->value == target) {
        return true;
    }
    if (target < root->value) {
        return search(root->left, target);
    } else {
        return search(root->right, target);
    }
}
```

查找不修改树，所以不需要 `Node*` 返回值，只需要 `bool`。

### 查找 6 的路径

```text
8 → 3 → 6
```

判断过程：

```text
6 < 8  → 去左边
6 > 3  → 去右边
6 == 6 → 返回 true
```

### 查找 5 的路径

```text
8 → 3 → 6 → 4 → nullptr
```

最终返回 `false`。

### 编译 warning 与修正

最初写成：

```cpp
if (target < root->value) {
    return search(root->left, target);
} else if (target > root->value) {
    return search(root->right, target);
}
```

编译器提示：

```text
non-void function does not return a value in all control paths
```

这是因为编译器不能证明 `else if` 一定覆盖所有剩余情况。  
把第二个分支改成 `else` 后，所有控制路径都有返回值：

```cpp
if (target < root->value) {
    return search(root->left, target);
} else {
    return search(root->right, target);
}
```

程序逻辑上虽然不会走到“函数末尾无返回值”，但 C++ 编译器仍然要求显式覆盖所有路径。

## 六、查找最小值 `find_min`

BST 中，一个子树的最小值一定在最左边。

```cpp
Node* find_min(Node* root) {
    if (root == nullptr) {
        return nullptr;
    }

    while (root->left != nullptr) {
        root = root->left;
    }

    return root;
}
```

整棵树一直往左：

```text
8 → 3 → 1
```

所以 `find_min(r)->value == 1`。

根节点右子树：

```text
10
  \
   14
  /
 13
```

从 `10` 开始没有左孩子，所以最小值就是 `10`。

## 七、删除 `remove_node`

删除必须保证剩下的树仍然是 BST，因此分三种情况。

### 情况 1：删除叶子节点

例如删除 `7`：

```text
    6
   / \
  4   7
```

```cpp
delete root;
return nullptr;
```

返回 `nullptr` 后，父节点接收它：

```cpp
root->right = remove_node(root->right, value);
```

于是父节点的右指针变成空。

### 情况 2：只有一个孩子

例如删除 `14`，它只有左孩子 `13`：

```text
14
 /
13
```

必须先保存孩子地址：

```cpp
Node* temp = root->left;
delete root;
return temp;
```

顺序不能反。执行 `delete root` 后，不能再安全访问 `root->left` 或 `root->right`。

如果只有右孩子，则保存 `root->right`，原理相同。

### 情况 3：有两个孩子

例如删除 `3`：

```text
        8
       /
      3
     / \
    1   6
       / \
      4   7
```

不能直接删除 `3`，否则左右子树无处连接。本课选择“后继节点”：

> 后继节点 = 右子树中的最小节点。

对于 `3`，右子树是：

```text
6
/ \
4 7
```

最小节点是 `4`。

操作步骤：

1. 找到 `successor = find_min(root->right)`
2. 把 `successor->value` 复制到当前节点
3. 从右子树中递归删除原来的后继节点

```cpp
Node* successor = find_min(root->right);
root->value = successor->value;
root->right = remove_node(root->right, successor->value);
```

为什么用后继？

因为后继是“比当前节点大的所有值中最小的一个”。  
用它替换当前节点后，左子树仍然都比它小，右子树仍然都比它大，BST 规则保持成立。

## 九、复杂度

BST 的插入、查找、删除都需要先沿树向下寻找位置。

| 情况 | 时间复杂度 |
|---|---:|
| 平衡 BST（接近完全树） | 约 `O(log n)` |
| 退化 BST（类似链表） | `O(n)` |

例如按顺序插入：

```text
1, 2, 3, 4, 5
```

会形成：

```text
1
 \
  2
   \
    3
     \
      4
       \
        5
```

这时查找 `5` 必须走过所有节点，所以最坏是 `O(n)`。

## 十、当前限制

1. **整棵树尚未统一释放内存**  
   目前通过 `delete root` 删除单个节点，但没有写销毁整棵树的函数。  
   这会在 L24 的 RAII / 智能指针部分系统处理。

2. **重复值会被忽略**  
   插入只处理 `<` 和 `>`，因此重复值不插入。以后可以选择忽略、计数、放到固定一侧等策略。

3. **删除使用后继值复制**  
   当前代码复制后继节点的值，而不是移动节点本身。这是常见实现，后续学习红黑树或工程代码时可以继续讨论节点重连方式。

## 十二、结课结论

本课最重要的三句话：

1. **BST 的规则是左小右大，而且每棵子树也必须满足。**
2. **插入、查找、删除都沿左右分支递归前进；插入和删除必须把返回的根节点接回父节点。**
3. **删除双孩子节点用后继节点替换，才能继续满足 BST 规则。**
